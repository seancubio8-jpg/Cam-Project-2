# Project 2 — Harborlight Hotel Booking System
Open `index.html` in a browser. Select a room, enter guest count and dates, and submit to save a demo reservation. It checks room capacity and overlapping date ranges. Reservations persist in localStorage.
- `index.html`: room listings and booking form
- `styles.css`: responsive hotel theme
- `script.js`: date validation, capacity checks, overlap logic, totals and localStorage
- `assets/`: hotel, room and calendar SVG illustrations
This is a front-end demo only. No real hotel inventory, backend, database, email or payment service is connected. Production booking requires server-side transactions/locking and secure guest-data handling.
